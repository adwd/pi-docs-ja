# Pi

Pi は、ターミナルから操作できる拡張可能な AI エージェントです。目標と作業フォルダーを指定すると、ファイルの確認、コマンドの実行、内容の編集、複数ステップのタスクの処理を行えます。

Pi は、ソフトウェア開発、調査メモ、執筆プロジェクト、データファイル、趣味の作業に使用できます。Pi をそのまま使用することも、ワークフローに適応するようプロンプトで指示することも、SDK を使用して Pi を基盤とする別のアプリケーションを構築することもできます。

## Pi を使い始める

Pi を初めて使用する場合は、[クイックスタート](quickstart.md)に従って Pi をインストールし、モデルに接続して、最初のタスクを完了してください。

Pi がすでにインストールされている場合は、実行したい操作を選択してください。

- [Pi を対話的に使用する](usage.md)ことで、ファイルの追加、コマンドの実行、進行中の作業への指示、結果のエクスポートができます。
- [モデルを選択する](models.md)か、サブスクリプション、API キー、ローカルモデル、または互換性のあるエンドポイントに接続します。
- [セッションを続行または分岐する](sessions.md)ことで、履歴を失わずに作業を再開したり、別のアプローチを検討したりできます。
- 好み、作業フォルダー、指示、再利用可能なリソースに合わせて [Pi を設定します](configuration.md)。
- ツール、コンテキスト、セッション、エージェントループなど、[Pi の仕組みを理解します](how-pi-works.md)。

## Pi をカスタマイズする

Pi では、プロンプトの再利用、専門的な指示の読み込み、実行可能な連携機能の追加、ターミナルインターフェースの変更、モデルサービスへの接続、これらのリソースのパッケージとしての配布が可能です。
ニーズを満たす最小限の仕組みを選択するには、[クイックスタートのカスタマイズ選択ガイド](quickstart.md#choose-how-to-customize-pi)を使用してください。

## Pi を自動化または組み込む

- 単発タスクやスクリプトによるタスクには、[print モード](cli.md#invocation-and-output)を使用します。
- 1 回の実行から構造化イベントを取得するには、[JSON イベントストリームモード](json.md)を使用します。
- 別の Pi プロセスを制御するには、[RPC モード](rpc.md)を使用します。
- アプリケーション内で Pi を実行するには、[TypeScript SDK](sdk.md)を使用します。

## 安全に作業する

Pi のツールと拡張機能は、Pi プロセスの権限で実行されます。プロジェクトの信頼設定は Pi が読み込むプロジェクトリソースを制御しますが、ツール呼び出しをサンドボックス化するものではありません。信頼できないファイル、リポジトリ、拡張機能、または無人の自動化を使用する前に、[セキュリティ](security.md)を確認してください。
