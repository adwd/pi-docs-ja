# スラッシュコマンド

Pi のターミナルエディターで `/` と入力すると、現在のセッションで利用可能なコマンドを検索できます。このページでは、現在の Pi リリースに組み込まれているコマンドを一覧表示します。

拡張機能、プロンプトテンプレート、スキルによってコマンドを追加できます。したがって、Pi のコマンドメニューが、セッションに読み込まれているリソースの正確なリファレンスとなります。

## モデルと設定

| コマンド | 説明 |
|---|---|
| `/settings` | 設定を開きます |
| `/model [provider/model]` | モデルを選択します |
| `/thinking [level]` | 思考レベルを設定します |
| `/scoped-models` | 対話的な切り替えで使用するモデルを設定します |
| `/login [provider]` | プロバイダー認証を追加します |
| `/logout` | プロバイダー認証を削除します |
| `/llama` | 設定済みの llama.cpp ルーター上のモデルを管理します |

## セッションとコンテキスト

| コマンド | 説明 |
|---|---|
| `/new` | 新しいセッションを開始します |
| `/resume` | 保存済みの別のセッションに切り替えます |
| `/name [name]` | セッションの表示名を設定します。省略した場合は現在の名前を表示します |
| `/session` | 現在のセッション情報と統計を表示します |
| `/tree` | セッションツリー内を移動します |
| `/fork` | 以前のユーザーメッセージから新しいセッションを作成します |
| `/clone` | 現在のセッションを現在位置で複製します |
| `/compact [instructions]` | 現在のコンテキストを圧縮します。必要に応じてカスタム指示を指定できます |
| `/import <path>` | JSONL セッションをインポートして再開します |

## エクスポートと共有

| コマンド | 説明 |
|---|---|
| `/copy` | 最後のアシスタントメッセージをコピーします |
| `/export [path]` | セッションを HTML または JSONL としてエクスポートします |
| `/share` | セッションをアップロードし、閲覧用リンクを返します |
| `/bug [description]` | Pi の開発者向けに非公開のバグレポートを作成します |

セッションをエクスポートまたは共有する前に、その内容を確認してください。セッションには、プロンプト、ツールの引数、コマンド出力、ファイルの内容、および会話中に露出した認証情報が含まれる場合があります。

## ランタイムとプロジェクト

| コマンド | 説明 |
|---|---|
| `/trust` | プロジェクトの信頼に関する判断を、今後の Pi プロセス用に保存します |
| `/reload` | キーバインド、拡張機能、スキル、テンプレート、テーマ、コンテキストファイルを再読み込みします |
| `/hotkeys` | 有効なキーボードショートカットを表示します |
| `/changelog` | 変更履歴の項目を表示します |
| `/quit` | Pi を終了します |

## リソースによって追加されるコマンド

- 拡張機能は、独自の引数と補完動作を持つコマンドを登録できます。
- 各プロンプトテンプレートは、そのテンプレート名で利用できます。
- スキルコマンドが有効な場合、スキルは `/skill:name` として利用できます。

検出対象のコマンドリソースを追加または変更した後は、`/reload` を使用してください。読み込みと命名の規則については、[拡張機能](extensions.md)、[プロンプトテンプレート](prompt-templates.md)、および[スキル](skills.md)を参照してください。
